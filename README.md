# 背單字網站

一個簡單的前端單字學習網站，使用HTML、CSS、JS開發，採用銀色Y2K風格。

## 功能特色

- **翻頁學習**：可以逐頁瀏覽單字卡片
- **卡片翻轉**：正面顯示英文單字，背面顯示詳細資訊（翻譯、詞性、例句、字根分析）
- **管理頁面**：方便管理者新增單字，並可透過 API 搜尋相關內容
- **本地儲存**：使用localStorage儲存單字資料
- **銀色Y2K風格**：現代感十足的視覺設計

## 檔案結構

- `index.html` - 主學習頁面
- `admin.html` - 管理頁面
- `styles.css` - 樣式檔案
- `script.js` - 主頁面邏輯
- `admin.js` - 管理頁面邏輯

## 使用方法

1. 開啟 `index.html` 開始學習
2. 使用上一頁/下一頁按鈕瀏覽單字
3. 點擊翻轉卡片查看詳細資訊
4. 點擊「管理單字」連結進入管理頁面新增單字

## 使用 API （可選）

網站提供一個簡單的本機 API，可將單字儲存在 `data.json`：

1. 安裝依賴：

```bash
npm install
```

2. 啟動伺服器：

```bash
npm start
```

伺服器會在 `http://localhost:3000` 提供靜態檔案與 API，管理頁面將會以 `/api/items` 方式儲存單字。
